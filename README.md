# cybersecurity_bootcamp_project
# Machine Learning-Based Network Intrusion Detection System Using NSL-KDD

## Project Overview

This project implements a machine-learning-based Network Intrusion Detection System (NIDS) to classify network connections as **Normal** or **Attack**.

The system uses the NSL-KDD dataset and compares two machine-learning algorithms: Decision Tree and Random Forest. The models are evaluated using accuracy, attack precision, attack recall, Attack F1-score, and false-positive rate.

The project also supports batch prediction using CSV files and exports the predicted results.

## Objectives

- Develop a machine-learning-based network intrusion detection prototype.
- Use the NSL-KDD dataset for training and testing.
- Compare Decision Tree and Random Forest classifiers.
- Evaluate model performance using multiple metrics.
- Support CSV-based prediction and result export.

## Dataset

**Dataset:** NSL-KDD

NSL-KDD is a benchmark dataset used for evaluating network intrusion detection systems.

- [NSL-KDD Dataset – Canadian Institute for Cybersecurity](https://www.unb.ca/cic/datasets/nsl.html)
- [NSL-KDD Dataset Files – GitHub](https://github.com/defcom17/NSL_KDD)

The project uses the following files:

| Dataset File | Description |
|---|---|
| `KDDTrain+.txt` | Training dataset |
| `KDDTest+.txt` | Testing dataset |

Dataset dimensions:

| Dataset | Rows | Columns |
|---|---:|---:|
| KDDTrain+ | 125,973 | 43 |
| KDDTest+ | 22,544 | 43 |

Download the dataset and place the required files in the project directory.

## Machine Learning Models

### Decision Tree
A supervised machine-learning algorithm that learns decision rules from the dataset.

### Random Forest
An ensemble learning algorithm that combines multiple decision trees to make predictions.

The models are compared using validation Attack F1-score for model selection.

## Methodology

1. Load the NSL-KDD training and testing datasets.
2. Separate input features and target labels.
3. Preprocess numerical and categorical features.
4. Train Decision Tree and Random Forest classifiers.
5. Evaluate the models using validation data.
6. Select a model based on validation Attack F1-score.
7. Evaluate the models on the held-out test dataset.
8. Accept CSV data for prediction and export the results.

## Setup and Execution

### 1. Install Python

Install Python 3.10 or a compatible version supported by the required libraries.

### 2. Download the Project

Download or clone the project and open the project folder in VS Code or a terminal.

### 3. Install Dependencies

Run the following command:

```bash
pip install -r requirements.txt
```

### 4. Add the Dataset

Download the NSL-KDD dataset and place `KDDTrain+.txt` and `KDDTest+.txt` in the project directory or the location expected by the script.

### 5. Run the Project

```bash
python network_intrusion_detector.py
```

The program trains and evaluates the models and generates the results.

## Results

### Model Performance Comparison

The following results were obtained from the held-out test dataset.

| Metric | Decision Tree | Random Forest |
|---|---:|---:|
| Accuracy | 79.93% | 77.90% |
| Attack Precision | 95.85% | 96.96% |
| Attack Recall | 67.67% | 63.15% |
| Attack F1-score | 79.33% | 76.49% |
| False-Positive Rate | 3.87% | 2.62% |

### Confusion Matrix

| Outcome | Decision Tree | Random Forest |
|---|---:|---:|
| Normal correctly classified (TN) | 9,335 | 9,457 |
| Normal flagged as attack (FP) | 376 | 254 |
| Attack missed (FN) | 4,149 | 4,729 |
| Attack detected (TP) | 8,684 | 8,104 |

### Result Summary

Decision Tree achieved higher accuracy, attack recall, and Attack F1-score on the held-out test dataset. Random Forest achieved higher attack precision and a lower false-positive rate.

Random Forest was selected using validation Attack F1-score. The test results show that model performance can differ between validation and test datasets.

## Limitations

- The system is evaluated using the NSL-KDD benchmark dataset.
- It is an offline prototype and does not monitor live network packets.
- Some attack records are not detected by the models.
- Results on benchmark data may not represent performance on current real-world network traffic.

This project demonstrates the application of supervised machine learning to network intrusion detection using the NSL-KDD dataset. Decision Tree and Random Forest classifiers were trained and evaluated using multiple performance metrics. The results highlight the trade-off between attack detection and false-positive reduction.
